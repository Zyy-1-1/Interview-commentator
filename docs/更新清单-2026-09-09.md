# 2026-09-09 更新清单

本次更新扩展应聘者侧产品面:岗位大厅从「裸列表」升级为**多条件筛选 + 官方精选岗位**,新增**牛客式匿名交流区**,并把「简历评审(人岗匹配)」拆为独立页面。同时修正了一处 LLM 超时配置缺陷。

## 已完成

### 1. 岗位大厅分类筛选(任务4)

- `jobs` 表新增 9 个分类字段:岗位类别(`category`)、最低学历(`education`)、薪资区间(`salary_min/max`,单位千元/月)与年薪月数(`salary_months`)、招聘类型(`recruit_type` 校招/社招/实习)、专业要求(`majors`)、工作城市(`location`)、官方精选标记(`is_official`),启动期幂等补列迁移,类别与招聘类型建索引。
- `GET /api/jobs` 支持 `category / education / recruit_type / major / salary_min / salary_max / q`(关键词匹配标题、公司、JD 正文)组合筛选;专业为自由文本包含匹配;薪资为区间重叠语义(期望下限 ≤ 岗位上限且期望上限 ≥ 岗位下限)。
- 新增 `GET /api/jobs/facets`:从已上架岗位聚合真实存在的类别/学历/招聘类型与薪资范围,供前端筛选栏动态渲染(不写死选项)。
- 前端 `JobHallView` 重写为筛选大厅:类别/学历/招聘类型下拉、薪资区间、专业与关键词输入、结果计数与重置。

### 2. 官方精选岗位数据

- 新增 `scripts/official_jobs.py`:18 个多行业官方精选岗位(互联网/能源央企/金融/制造新能源/快消/医药/游戏/建筑/财会),含真实公司、薪资梯度与招聘类型;`dimensions` 结构与 JD 分析 Agent 输出一致,离线预写、不调用 LLM,保证演示零成本可复现。
- 数据来源与口径在文件头注明(2026-09 检索的各公司校招公告与牛客开奖薪资,属演示数据,非实时招聘情报)。

### 3. 牛客式匿名交流区(任务5)

- 新增三张表:`posts`(帖子)、`comments`(评论)、`post_likes`(点赞,`post_id + token_hash` 唯一约束保证幂等 toggle),级联删除。
- 新增 `app/api/community.py`:发帖、帖子列表(带 `likes_count / comment_count / liked_by_me`)、帖子详情、评论、点赞切换;公开可读可发,无账号体系。
- **匿名身份设计**:浏览器本地随机生成令牌(`access.js getCommunityToken`,sessionStorage),请求头 `X-Community-Token` 传入;服务端只存 SHA-256 哈希并派生昵称(如「面评家用户_3f8a」),不存明文、不可逆推,兼顾「同一会话身份稳定」与隐私叙事。
- 输入校验:`extra="forbid"`、去首尾空白、标题 2-100 字、正文 ≤5000 字、评论 ≤1000 字。
- 前端 `CommunityView`(列表 + 发帖)与 `PostDetailView`(详情 + 评论),路由 `/community`、`/community/:id`。

### 4. 简历评审独立页

- 新增 `MatchReportView`(`/match`):上传简历 → 选目标岗位 → 人岗匹配评审单(总分 + 维度得分/简历证据 + 亮点/缺口),复用既有 `GET /api/candidates/{id}/match/{jobId}`。
- 上传后候选人凭据(id + 一次性 access_token)存 sessionStorage(`storeCandidate/getCandidate`),页面刷新后可继续使用。
- `ResumeAnalysisView` 收敛为「上传 → 选风格 → 直接开始面试」,评审职能移交给独立页。

### 5. 演示数据升级

- `scripts/make_demo.py`:清空重建七张表,产出 **23 个岗位(18 官方精选 + 5 通用演示)+ 20 份简历 + 5 场面试 + 6 个交流区帖子(8 条评论、36 次点赞)**;帖子为面经/爆料/求助三类,支撑交流区演示。
- `start_all.bat` 重置提示文案同步。

### 6. LLM 超时配置修正

- 实测整份简历 × JD 的人岗匹配调用(qwen-plus,输出全维度证据 JSON)单次约 **25.8 秒**,而原默认单次上限恰为 25.0 秒 —— 匹配接口在超时边缘随机失败(重试同样撞线,最终 502)。
- `config.py` 默认值放宽:`LLM_TIMEOUT_SECONDS` 25→45,`LLM_TOTAL_TIMEOUT_SECONDS` 75→90,字段上限 80→120;总预算内仍逐次收紧、鉴权/参数错误不重试的语义不变。

## 使用注意

- 交流区无审核与删除接口,帖子仅随 `make_demo.py` 重置清空;公开试用前需补充内容治理(举报/敏感词/管理端删帖)。
- 匿名令牌存 sessionStorage,关标签页即换身份,符合「会话内稳定」的设计目标,也意味着清浏览器数据后「我赞过」判定失效(仅影响本人视图)。
- 大厅筛选参数向后兼容:不带任何参数时行为与旧版一致(仅 `status=approved` 全量)。
