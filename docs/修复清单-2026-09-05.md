# 2026-09-05 分批修复清单

依据 [AIC 参赛评审](AIC参赛项目改进评审-2026-09-05.md)推进，每批验证后独立提交并推送。评审保留为修复前的基线，本文件记录实际进展。

## 第一批：匹配图表和报告重试

- 匹配分析结束并挂载结果容器后再绘图；换简历、再次匹配和页面卸载时销毁旧实例。
- 忽略换简历后迟到的旧匹配响应，避免结果串到下一份简历。
- 报告重新生成成功后清空旧错误，立即显示结果与图表。
- 新增前端离线组件回归入口 `npm.cmd test`，接入 CI；使用现有 Vue 依赖，无新增运行依赖。
- 纳入此前已完成的 `AGENTS.md` 和评审文档，`.agents/` 继续保持忽略。

验证：5 项前端组件回归通过，`npm.cmd run build` 成功，Git 差异检查通过。真实模型、浏览器 TTS 和镜像运行不由组件测试证明。

## 第二批：模型输出边界与会话规则

- 简历采用字段级结构校验：允许缺失区域为空，拒绝错误的嵌套类型；上传接口统一返回 422 并清理临时文件。
- 面试问题必须为非空文本；错误问题或判断结构进入状态机兜底，避免在响应序列化时出现 500。
- JSON 协议拒绝数组、null 和非标准 NaN / Infinity；JD 权重、匹配分、逐轮质量判断过滤非有限数和布尔值。异常日志不包含原始模型正文。
- 从配置读取题目上限并在创建面试时冻结到快照，提示词同步使用会话上限。已有会话保持原规则。
- 更新 README 的配置和错误处理说明。

验证：针对性回归 48 项通过；完整后端离线测试 60 项通过，2 项真实模型用例未运行；Git 差异检查通过。最终报告的证据与计分契约在下一批单独修复。

## 第三批：证据约束评分与报告可复核性

- 报告证据必须来自同维度的候选人单条消息；保留消息编号，拒绝伪造、错编号、错角色、跨维度和拼接引用。
- 未考察与证据不足采用不同状态，分数为 null；回答较差仍可凭原话计低分。覆盖不全或输入截断时不计算完整总分，展示有效评分覆盖率和部分得分。
- 评估沿用创建面试时的岗位维度、权重与岗位名；开场自我介绍不自动计入第一项技能。
- 全场上限收尾保留最后一条回答，不继承上一轮质量判断；较长回答不再固定丢弃 500 字后的内容，超过输入预算时明确标注。
- 报告页支持展开原始问答，未评分维度不当作 0 分绘图；历史报告保留并标明未按新证据规则核验。

验证：完整后端离线测试 74 项通过，2 项真实模型用例未运行；前端组件回归 7 项通过，生产构建成功，Git 差异检查通过。原话定位并不证明评分准确、论据充分或简历事实真实。

## 第四批：后台报告、并发去重与等待预算（2026-09-06）

- 收尾落库后在后台线程生成报告，模型等待不再叠加到最后一次答题请求；后台任务使用独立数据库会话。
- 新增可查询的生成状态、失败信息与重试入口；数据库原子领取和任务编号防止重复评估、过期任务覆盖新结果。
- 服务重启或任务中断后，超过任务期限可手动重试；已有报告复用缓存，查询状态不调用模型。
- 模型多次尝试共享 75 秒重试预算，默认单次网络超时 25 秒；鉴权和参数错误不重复请求。
- 报告页查询处理中状态、成功后绘图、失败后可重试，离开页面清理轮询；鉴权错误不显示生成入口。
- 面试结束页和收尾语不再提前宣布报告生成成功。存量数据库通过幂等补列兼容，原有报告保持不变。

验证：完整后端离线测试 81 项通过，2 项真实模型用例未运行；前端组件回归 11 项通过，生产构建成功。覆盖并发领取、失败重试、过期结果隔离、补列幂等和时间预算。当前后台任务依赖应用进程，尚未引入独立任务队列；网络超时不代表严格的进程执行时限。

## 第五批：简历原文进入追问背景（2026-09-06）

- 创建面试时定位项目、经历和技能的原文片段，保留编号、字段路径和字符位置，固定到会话快照；不主动加入基础身份字段。
- 仅提供能在原文定位的片段，最多 16 段、3500 字符；没有原文的旧记录安全回退到岗位与对话出题。
- 三种风格共享同一份简历背景；流程纠偏按维度关键词选择相关项目，避免只会泛泛要求举例。
- 开场明确为经历暖场，随后正式考察；简历背景不直接贡献最终分数，仍需本场回答证据。
- 拒绝没有有效维度清单的岗位创建面试；增加异步任务和数据库优化两份合成简历供回归与演示准备。
- 修正文档中“共享协议即公平”的过度表述。

验证：完整后端离线测试 94 项通过，2 项真实模型用例未运行；覆盖原文位置、上下文预算、不同材料隔离、会话冻结、相关项目选取及无效大纲。真实追问的个性化程度和评分公平性尚未进行模型对照实验。
